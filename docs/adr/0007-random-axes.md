# 7. Draw the chart's axes at random

- Status: Superseded by [0016](0016-precomputed-trait-dictionary.md)
- Date: 2026-09-27

## Context

A fixed set of axes makes every character look like a variation on the same template.

## Decision

Draw the axes from a dictionary of traits for each reading.

## Consequences

Some traits will never be addressed by the story and stay grey. That is a result in itself, not a failure.
